** Data preparation:
+ You can download the dataset from this URL: https://data.mendeley.com/datasets/m7ndn58sv6/1
+ Extract the dataset to path:
#+begin_src sh
hgt-carotid-segmentation/data
#+end_src

+ Your data path should look like this:
#+begin_src sh
data
└── DATASET_CUBS_tech
    ├── CF
    ├── CUBS-tech-SNR-geometry.xlsx
    ├── Folds
    ├── images
    ├── LIMA-Profiles
    ├── LIMA-Profiles-interpolated
    └── readme-CUBS-tech.txt
#+end_src

** Python and dependencies setup:
+ Clone this repository:
#+begin_src sh
git clone git@github.com:miftanurfarid/hgt-carotid-segmentation.git
#+end_src
+ Go to the cloned repository folder:
#+begin_src sh
cd ~/Documents/hgt-carotid-segmentation
#+end_src
+ Install a specific Python version:
#+begin_src sh
uv python install 3.13.18
#+end_src
+ Create a Python environment using that version:
#+begin_src sh
uv venv --python 3.13.18 .venv
#+end_src
+ Activate the Python environment:
#+begin_src sh
source .venv/bin/activate
#+end_src
+ Install the required packages:
#+begin_src sh
uv pip install -r requirements.txt
#+end_src
