#+title: Readme

* Data preparation:
+ You can download the dataset from this URL: https://data.mendeley.com/datasets/m7ndn58sv6/1
+ Extract the dataset to path: =hgt-carotid-segmentation/data=
+ Your data path should look like this:
#+begin_src sh
/home/mnf/Documents/hgt-carotid-segmentation/data
├── __MACOSX
│   └── DATASET_CUBS_tech
└── DATASET_CUBS_tech
    ├── CF
    ├── CUBS-tech-SNR-geometry.xlsx
    ├── Folds
    ├── images
    ├── LIMA-Profiles
    ├── LIMA-Profiles-interpolated
    └── readme-CUBS-tech.txt
#+end_src

* Python and dependencies setup:
+ Clone this repository: ~git clone git@github.com:miftanurfarid/hgt-carotid-segmentation.git~
+ Go to the cloned repository folder: ~cd ~/Documents/hgt-carotid-segmentation~
+ Install a specific Python version: ~uv python install 3.13.18~
+ Create a Python environment using that version:  ~uv venv --python 3.13.18 .venv~
+ Activate the Python environment: ~source .venv/bin/activate~
+ Install the required packages: ~uv pip install -r requirements.txt~
